How to make updates permanent?

Modifying fields on this page and clicking **Save Changes** updates your browser's local view immediately so you can test it.

To make the changes permanent for all public visitors on your live website, follow these steps:

  1. Modify the contents on this panel to your liking.
  2. Click the **Export config.json** button at the top-right.
  3. Save the downloaded `config.json` file inside your local folder, replacing the old `config.json`.
  4. Run a Git Commit and Push to your repository: 
    git add config.json
git commit -m "Update website content"
git push origin main

Note: GitHub Pages may take 1-2 minutes to deploy the new file after you push.
