E-Commerce Platform Vulnerability Assessment

Storefront Application Clickjacking Security Audit

Identified and verified a clickjacking (UI redirection) flaw during security research labs on an active storefront web server. Verified the bypass and responsibly coordinated a patch submission with the client.

MEDIUM Missing Frame Isolation Headers (Clickjacking) +

The web server failed to enforce defensive boundaries, completely lacking legacy X-Frame-Options and modern Content-Security-Policy (CSP) frame-ancestors tokens. This allowed the authentication page to load inside unauthorized external frames.

LOW Proof of Concept Frame Pipeline +

Confirmed exposure by building a lightweight HTML frame wrapper that loads the user login fields inside a controlled, mock attacker-facing layer without triggering browser exceptions.
